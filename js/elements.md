# HTML components

## `Element`

* `getAttribute()`
* `setAttribute()`
* `getAttributeNames()`

* `localName` (the local part of an XML tag)
* `tagName` (capitalised, === `nodeName` for `Element`)
* `nodeName` (capitalised)

* `innerHTML` (get or set to modify content - unsafe)
* `outerHTML` (includes the element itself)

## `Attr`

* `name` (qualified name)
* `localName` (local part of an XML attribute, eg. `xml:lang` returns `lang`)
* `value`
* `ownerElement`
