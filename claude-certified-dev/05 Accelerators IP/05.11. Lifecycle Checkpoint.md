Source: Developer Module 5, screen 11 of 25. Title: "Checkpoint 4: place the work in the right phase". Not submitted, so the course's answer key wasn't revealed; placements below are my own reading of 05.10.

## The task
Place each activity in one lifecycle phase: requirements, design, test, deploy, operate.

| Activity | My placement | Why |
|---|---|---|
| (a) Pinning the full model ID and keeping the prior version | Deploy | "Deploy: pin the version" |
| (b) Gating promotion on the eval result before a version goes to production | Deploy | "gate promotion on the eval" is part of the deploy phase |
| (c) Deciding data must be processed in a specific region | Requirements | Residency is an infrastructure requirement |
| (d) Instrumenting token cost and latency per call in production | Operate | "Operate: instrument cost, latency, errors" |
| (e) Choosing Amazon Bedrock because the customer holds its compliance posture there | Design | "Design: choose the platform, the model, the trust boundaries" |

Note: the options included "test" but none of the five clearly belongs to it; (b) is the closest candidate but 05.10 puts the promotion gate in deploy.
