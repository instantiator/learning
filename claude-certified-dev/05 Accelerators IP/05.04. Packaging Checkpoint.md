## The task
A "reusable" code-review agent template has one defect: a customer-specific value hardcoded where a parameter belongs. Identify it, then write the corrected function signature and the parameterised line.

## The template as shipped
```python
# agent_template.py : "reusable" code-review agent
def build_review_agent():
    return Agent(
        model="claude-opus-4-8",
        system_prompt=SYSTEM_PROMPT,
        tools=[read_file, run_linter],
        repo_path="/home/acme/checkout-service",   # customer repo
    )
```
(The screen notes: confirm the current model ID in the Anthropic models docs at build time.)

## My answer
The defect is `repo_path="/home/acme/checkout-service"`, a path to one customer's repository.
```python
def build_review_agent(repo_path: str, model: str = "claude-opus-4-8"):
    return Agent(
        model=model,
        system_prompt=SYSTEM_PROMPT,
        tools=[read_file, run_linter],
        repo_path=repo_path,
    )
```
The model is also worth exposing as a parameter with a documented default, since 05.02's checklist lists model and thresholds among per-customer values, but the screen asks for the customer path as the single defect.
