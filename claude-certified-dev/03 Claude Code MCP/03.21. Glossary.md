# 03.21 Glossary: Key Terms (about 3 min)

Source: Developer Module 3, screen 21 of 22. Alphabetical list of the module's terms, restated briefly in my own words.

- **Claude Agent SDK:** a programmable interface to the same agent loop Claude Code runs in the terminal. From code you can invoke the loop, set the permission mode and available tools, and run tasks with no interactive session. The same permission model and deny rules apply as in the terminal.
- **CLAUDE.md:** a Markdown file at the root of a Claude Code project whose contents are prepended to the context at the start of every session. It holds universal constraints, conventions and commands that apply unconditionally. Past roughly 200 to 300 lines, it risks diluting critical rules through sheer content weight.
- **Hook:** a command bound to a Claude Code lifecycle event (`PreToolUse`, `PostToolUse`, `UserPromptSubmit`, `Stop`, and others). Unlike `CLAUDE.md` instructions, hooks run deterministically at the event whatever the model decides. A `PreToolUse` hook can exit with code 2 to block a tool call before it runs.
- **MCP (Model Context Protocol):** an open communication layer letting a client such as Claude Code connect to a server that exposes tools, resources and prompts, defining how the client discovers and calls them. It moves tool definition and upkeep out of individual applications into a reusable server any MCP client can attach to.
- **MCP transport:** the channel between MCP client and server. `stdio` runs the server as a local subprocess on the client's machine; HTTP connects to a remotely hosted server over a network. The choice decides where the server can run and who can connect.
- **Permission mode:** a Claude Code setting for how often the agent stops to ask before executing tool calls, from `default` (prompts before nearly every action) to bypass modes (no prompts). Deny rules override any mode, and an enterprise-level deny can't be bypassed by any individual configuration.
- **Plugin:** a versioned bundle of Claude Code components (skills, hooks, subagents, MCP server configurations) distributed through a marketplace. Installing it gives the recipient the author's setup in one step; administrators can deploy plugins organisation-wide through managed settings.
- **Rules instruction file:** a file that scopes guidance to a path or condition. Unlike `CLAUDE.md`, which always loads, a path-scoped rules file activates only when Claude Code is working on matching files, keeping path-specific guidance out of the main memory file.
- **Subagent:** a separate execution context launched by Claude Code for a delegated task. It inherits neither the main conversation's context nor accumulated files, starts clean, does the work, and returns only a summary. Using subagents for exploration keeps the main session from filling with content that won't be reused.
