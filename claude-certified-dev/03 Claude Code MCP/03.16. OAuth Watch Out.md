# 03.16 Enterprise Integration: Watch Out (about 3 min)

Source: Developer Module 3, screen 16 of 22. Title: "The OAuth connection that worked in staging and failed in production".

## The trap
An OAuth connection worked end to end in staging, so the production cutover felt routine. The missed fact: **OAuth redirect URIs are registered per host** and are often governed per environment. A working staging flow doesn't mean the production host is authorised to complete sign-in.

## What happened (illustrative post-deployment review)
- Every production sign-in through the MCP connection was failing with a **redirect URI mismatch**.
- The developer had registered the OAuth app for the staging host during development, then moved to production the week before. The integration had passed every staging test.
- The reviewer's diagnosis: the OAuth provider only accepts redirect URIs that have been explicitly registered; the production host wasn't on the allowed list, so each sign-in hit the check, failed the match, and looped back to the sign-in screen.
- Fix: add the production redirect URI to the app registration. The reviewer added a second flag: check whether staging and production should be **separate app registrations**. Most enterprise customers require separate registrations per environment as part of their security policy, so sharing one across environments is the second issue.
- This was not a code defect: it was a per-host, per-environment configuration step the developer hadn't known to repeat for production.

## Takeaways
- Before moving any OAuth-authenticated MCP integration to a new environment, add the new host's redirect URI to the OAuth app registration.
- For regulated enterprise customers, confirm whether separate OAuth app registrations are required for staging and production.
- Put the registration step on the deployment checklist so it isn't discovered at the first production sign-in attempt.
(Relates to 03.15: OAuth is the right pattern for user-identity services, but it adds per-environment setup.)
