# 03.01 Module Introduction (about 2 min)

Source: Developer Module 3, Claude Code, MCP & Integration, screen 1 of 22. 9 sections, 22 screens, about 142 minutes.

## Framing
Claude Code is the terminal-native way to run the same model you used through the API. It adds a permission layer, a configuration system and team-sharing features, and MCP gives secure integration with external services. This module teaches configuring Claude Code and MCP for security and sound deployment. It builds on Module 2 and does not re-teach the agent loop, tool schemas or context engineering.

## Learning goals
1. **Loop and permissions:** run Claude Code through explore, plan, code, and pick a permission mode that matches the risk of the work, so the agent is productive without more authority than the task needs.
2. **Reviewing AI-generated code:** read output with calibrated trust, act on reliable findings, verify the shaky ones, and put a human review gate where a wrong call is costly.
3. **Durable project context:** `CLAUDE.md`, rules instruction files, hooks and subagents.
4. **Packaging workflows:** skills, custom commands and a plugin; author a skill once so it runs the same across Claude Code, the Messages API and the Agent SDK.
5. **MCP servers:** build one exposing tools, resources and prompts; choose the transport that fits how client and server communicate; set the configuration scope that controls who loads it.
6. **Enterprise integration:** connect Claude to enterprise systems, authenticate in ways a regulated customer accepts, and scope a code-modernisation engagement so it survives a security review.

## The recurring problem ("the build")
Work that runs fine on your machine, in your session or in staging now has to hold up when someone else runs it, in production, against real company systems. Each local convenience becomes a failure mode:
- a permission mode deletes a file that was never in scope;
- one rule gets buried under hundreds of lines;
- a skill points at a path that exists on no other machine;
- a committed key leaks within hours;
- a staging-only configuration step takes down the production connection.
The module teaches which configuration decision prevents which failure, before a teammate or an auditor hits it.

## Audience
Developers who already have Claude working in code and now need it to be configurable, shareable and safe to connect to real systems. Standard educational-content disclaimer applies (verify against Anthropic's docs; Anthropic's terms prevail).
