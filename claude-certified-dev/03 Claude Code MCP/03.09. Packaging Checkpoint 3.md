# 03.09 Packaging Workflows: Checkpoint 3 (about 3 min)

Source: Developer Module 3, screen 9 of 22. Title: "Checkpoint 3: place the skill in the right runtime". A matching exercise, not submitted; the answers below are the ones 03.08 (and 02.19) support. The course notes it lists four runtime situations so the match is complete.

Three teams (plus a fourth situation) want to reuse the same review-checklist skill. Match each to what must be configured:
- (1) Place `SKILL.md` in `.claude/skills` with a description that matches review requests.
- (2) Set `settingSources` explicitly so the Agent SDK loads skills from the project (don't rely on a default; confirm the current default in the Agent SDK reference).
- (3) Send the code-execution and skills beta headers, and write the skill so its steps don't depend on local files or local tools.
- (4) Define the agent as an API resource that lists the skill, set the `managed-agents-2026-04-01` beta header on the calls, and write the skill so its steps don't depend on local files (it runs in Anthropic's sandbox).

| Situation | Match | Why |
|---|---|---|
| A developer wants the skill to load when they ask for a review in the Claude Code terminal | **(1)** | Claude Code discovers skills from `.claude/skills` and loads on a description match. |
| A service calls the Messages API and wants the skill to run as part of the request | **(3)** | The API needs the beta headers, and the skill runs in a code-execution container with no local files or tools. |
| A scheduled headless job uses the Agent SDK and expects the repo's skill to load | **(2)** | In the SDK, whether filesystem sources load is controlled by `settingSources`; set it explicitly. |
| A product team wants the skill inside a long-running agent Anthropic hosts, reachable by agent ID across sessions | **(4)** | That's Managed Agents: the agent is an API resource, with its own beta header, running in Anthropic's sandbox. |

Takeaway: the skill file is the same; the loading mechanism and what the skill may touch are what change (03.08).
