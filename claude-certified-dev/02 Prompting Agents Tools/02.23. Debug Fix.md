## My suggested fixes (not the course's model answer)
These follow the bug list in 02.22; see the caveat there on which context-layer defect the course intends.

1. **Schema.** Replace "Gets data." with a description that says what it does, when to use it and when not to, and what it returns; and make the parameter self-describing.
   - Name the tool for what it fetches, e.g. keep `get_customer_data`, with a description like: "Retrieve the profile for one customer by customer ID. Use when the user asks about a specific customer's details. Do not use for order history or billing, which have their own tools. Returns the customer record."
   - Rename or document `id` as `customer_id` (string) with a format example.
   - Changes: tool selection and argument quality (02.07/02.08).
2. **Streaming.** Commit the assistant turn only when the stream completed.
   - After the `with` block: `if not stop_seen: discard blocks and retry (or raise)`, and only then build and append the assistant message.
   - Changes: an interrupted stream can no longer write a half-built `tool_use` into history (02.10/02.11).
3. **Context.**
   - Keep the thinking blocks: build `assistant_content` from **all** assembled blocks unchanged, with no `!= "thinking"` filter, because with thinking on and tools in use they must be returned as received (02.05).
   - Collect every `tool_result` for the assistant turn in one list and append them as **one** user message after the loop over blocks, so all results come back in the immediately following user turn (02.07, 02.16).
   - Changes: next-request validation no longer fails on a stripped signature or split results.
4. **Memory.** Stop concatenating every prior transcript into the live context.
   - Persist session history to external storage (or keep a summary written with a well-specified summariser prompt) and, in `build_session_history`, load only the relevant subset or the summary for the new session.
   - Changes: starting context stays bounded as sessions accumulate (02.19/02.20), and the window doesn't fill by a later session.
