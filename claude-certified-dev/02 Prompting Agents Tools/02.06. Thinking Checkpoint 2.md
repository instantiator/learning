# 02.06 Extended Thinking: Checkpoint 2 (about 3 min)

Source: Developer Module 2, screen 6 of 29. Title: "Checkpoint 2: Decide when extended thinking earns its cost". A matching exercise, not submitted; the answers below are the ones the teaching in 02.05 supports.

Match each task to one decision: "Never do this", "Leave it off", or "Enable it, budget for the planning step".

| Task | Decision | Why |
|---|---|---|
| Classify 50,000 support tickets into three labels overnight | **Leave it off** | Mechanical classification gains nothing from reasoning and would cost extra tokens at scale; a constrained prompt is enough. |
| Plan a multi-step refactor where each step depends on the previous one | **Enable it, budget for the planning step** | Dependent multi-step planning is where reasoning earns its cost. |
| Strip the thinking block from conversation history to save context before the next tool call | **Never do this** | Thinking blocks must go back to the API unchanged (carry-back rule); removing them breaks the next request. Manage context another way. |
