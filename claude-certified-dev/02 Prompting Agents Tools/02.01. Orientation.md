# 02.01 Orientation (about 2 min)

Source: Developer Module 2, Production-Grade Prompting, Agents & Tool-use, screen 1 of 29. 10 sections, 29 screens, about 209 minutes, 9 checkpoints.

## Framing
"Writing code that uses Claude is different from using Claude to write code." Beyond interactive chat, the engineer owns integrating Claude in code, handling its output reliably, and deploying something robust. Each topic targets a failure mode that is easy to miss in development and costly to fix later.

## The running scenario ("the build")
A Claude integration that worked in development has to survive production: longer sessions, bigger tool outputs, interrupted streams, tighter cost and latency limits, memory across turns, and irreversible actions. The module maps each implementation decision to the production failure it prevents.

## Learning goals
1. **Prompts:** system prompts, XML tags, few-shot examples, output constraints; diagnose an underperforming prompt.
2. **Extended thinking:** when to enable it, how to calibrate effort, and how to handle thinking blocks across tool-use turns.
3. **Tools:** write a tool schema Claude picks correctly; build the tool-use loop; handle multi-turn message blocks; single vs parallel tool calls.
4. **Streaming:** consume a stream, assemble events into complete content blocks, recover from a mid-stream interruption.
5. **Context engineering:** manage the window, compact, clear history between tasks, hand off to subagents.
6. **Agents:** workflow vs agent patterns, wiring tools and context into a loop, choosing a wiring path for your deployment, human-in-the-loop checkpoints for irreversible actions.
7. **Memory:** persistent storage patterns and choosing memory scope so state survives turns without inflating context cost.
8. **Multimodal and batch:** images and PDFs in message blocks, the Files API for reusable assets, Message Batches API for async high-volume work.

## Audience
Developers already comfortable coding who want to turn a prototype into a production system. It does not teach programming basics. Usual educational-content disclaimer applies (verify against Anthropic's docs; Anthropic's terms prevail).
