## The task
A prompt is meant to extract a JSON object from a support ticket with three fields: `category`, `urgency`, and a one-sentence `summary`. It has one defect; write the corrected system prompt.

## The broken prompt
- System: "You are a support ticket processor. Extract the key information from the ticket below."
- User: a `<ticket>` saying an API key stopped working after being rotated the night before, a production deployment is failing, and it must be fixed immediately.

## My read of the defect (not the course's model answer)
The system prompt never states the output form. "Extract the key information" names no fields, no JSON shape, no allowed values for category or urgency, and no "return only JSON". This is the "wrong shape" row from 02.02: an output constraint is missing.

A fix in the spirit of 02.02/02.03 would:
- name the three fields exactly (`category`, `urgency`, `summary`);
- fix the allowed values for category and urgency (for example a short enumerated list for each);
- cap `summary` at one sentence;
- say to return only the JSON object with no other text;
- optionally add one few-shot example in XML tags, and/or enforce the shape with structured outputs (`output_config.format`).
