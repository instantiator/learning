```python
OUTPUT_DIR = "/workspace/output"          # fixed, never taken from the page
RETRYABLE = (RateLimitError, APIConnectionError, InternalServerError)

def answer(question, page_url):
    page = fetch(page_url)                # treated as data, not instructions
    notes = read_file("/workspace/input/notes")
    # Security: path chosen by us; PreToolUse hook also denies writes outside OUTPUT_DIR and logs an audit entry
    write_file(f"{OUTPUT_DIR}/summary.md", summarize(page))

    for attempt in range(5):              # Failure handling: backoff + jitter, retryable errors only
        try:
            resp = client.messages.create(model=MODEL_FOR_TASK, max_tokens=SIZED_MAX_TOKENS,
                                          messages=msg(question))
            return resp.content[0].text
        except RETRYABLE:
            time.sleep(min(2 ** attempt + random.random(), 30))
    raise AnswerUnavailable("retries exhausted")   # explicit failure, not a None crash
```

## What each fix changes
| Layer | Change |
|---|---|
| Security | The write path no longer comes from untrusted content; a hook denies writes outside the permitted path and logs them. |
| Failure handling | Retries only transient errors, with exponential backoff and jitter, and fails explicitly when retries run out. |
| Cost / orchestration | Model and `max_tokens` chosen for the task, not fixed for every call (the third defect is my inference; see 04.19). |

Remember: no prompt wording is a security control, so enforce with a hook; backoff beats immediate retries because instant retries add load while the service is limiting you.
