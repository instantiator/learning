# 01.06 Module Quiz (about 5 min)

Source: Developer Module 1, screen 6 of 9. Four multiple-choice questions, paraphrased here. I did not submit the quiz, so the answers below are the ones the teaching screens support, not a scored result.

1. **A teammate says identical prompts must return identical text. Best response?**
   Answer: not necessarily. The model samples each next token from a probability distribution, so wording can vary even when both answers are correct. (See 01.02.)

2. **What separates model choice from reasoning mode?**
   Answer: model choice picks which family member runs; extended thinking is a per-call setting that any supporting model can have on or off. (See 01.03.)

3. **A short, well-specified classification task already works zero-shot. What does adding three examples most likely do?**
   Answer: adds token cost on every call for little or no gain. (See 01.04.)

4. **Thousands of inputs to process offline at the lowest cost. Which shape fits?**
   Answer: batch submission with polling. (See 01.05.)
