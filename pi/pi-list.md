```bash
pi list
```

- `npm:pi-web-access` - Provides web search, content fetching, and source checking capabilities.
- `npm:pi-mcp-adapter` - Enables integration with Model Context Protocol (MCP) servers for extended tool access.
- `npm:@tintinweb/pi-subagents` - Provides the Agent tool for launching autonomous sub-agents to handle complex multi-step tasks.
- `npm:@juicesharp/rpiv-todo` - Adds the todo tool for creating and managing task lists across multi-step workflows.
- `npm:@juicesharp/rpiv-ask-user-question` - Provides the ask_user_question tool for gathering structured input from users during execution.
- `npm:@plannotator/pi-extension` - Plannotator CLI integration for plan reviews, code reviews, and guided review workflows.
- `npm:pi-markdown-preview` - Enables rendering and exporting of Markdown/LaTeX content to PDF, HTML, or PNG formats.
- `npm:pi-meat` - Provides the meat tool for abridging diffs into readable summaries by filtering out mechanical noise.
- `git:github.com/DietrichGebert/ponytail` - Enforces minimalist coding practices with YAGNI principles to prevent over-engineering.
- `npm:@nilskluewer/pi-atlassian-mcp` - MCP integration for connecting with Atlassian services (Jira, Confluence).
